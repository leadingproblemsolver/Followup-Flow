# Five-minute demo script (record yourself; not yet recorded)

**0:00–0:45 Problem:** Small shops lose follow-ups in messaging inboxes. Say this is a hypothesis, not verified market research.

**0:45–1:35 Product:** Show the empty dashboard, add an inquiry, update its status, show the metrics, export CSV.

**1:35–2:40 Build:** Show `index.html` UI, `app.py` routes and SQLite persistence, then run `python -m unittest -v test_app.py`. Explain input validation and text-safe rendering.

**2:40–3:25 Scalability:** State the actual limitation: local-only single-instance app. Explain auth, tenant isolation, PostgreSQL, background reminders, monitoring as *future work*, not existing features.

**3:25–4:20 Business:** Target WhatsApp-heavy small shops. Illustrative free tier and $9/mo paid tier; interview 5 shops before claiming willingness to pay. Show the value of tracking open opportunity amounts, not fabricated recovered revenue.

**4:20–5:00 Technical defense:** Have duo members explain a field validation decision and reproduce an unseen bad-input test live. Clearly identify AI-assisted implementation and human-written contributions.
